## Entry

Try our Airplane Tray Table Pizza: one tray licked by 400 strangers, folded into the cheese, so every bite tastes like a red-eye to Cleveland with the seatbelt sign on.

## Why this wins

Everyone has stared at an airplane tray table and wondered who touched it last. This entry sells that universal shudder as a menu special: one tray, 400 strangers, folded straight into the cheese so there is no escape. The joke lands in one clean image — every bite tastes like a red-eye flight with the seatbelt sign stuck on — vivid, specific, and genuinely terrible in a way no sock, toothpaste, or soggy-cereal entry in this field has tried. One line, one real joke, zero wasted characters.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry line (no trailing newline) to `out/entry.txt`, reads it back to verify, and prints its SHA-256.
